# MATLAB Terminal Velocity Calculator

## Overview
This project calculates the terminal velocity of a spherical object falling through a fluid using Stokes' Law.

The program uses physical parameters such as sphere radius, density of the sphere, fluid density, dynamic viscosity, and gravitational acceleration.

## Objectives
- Understand the concept of terminal velocity.
- Apply Stokes' Law using MATLAB.
- Perform physics-based mathematical calculations.
- Develop basic MATLAB programming skills.

## Formula

\[
V_t = \frac{2r^2g(\rho_s-\rho_l)}{9\mu}
\]

Where:
- `Vt` = Terminal velocity (m/s)
- `r` = Radius of the sphere (m)
- `g` = Gravitational acceleration (m/s²)
- `ρs` = Density of sphere (kg/m³)
- `ρl` = Density of fluid (kg/m³)
- `μ` = Dynamic viscosity (Pa·s)
